# Ролики «Свободное время»

## Пастельный пилот

По умолчанию генератор использует новый розовый макет с моделью (`assets/pastel/pink.png`):
дата и свободные часы слева, фотография справа, контакты внизу. Каждое время — на маленькой
пастельной плашке с часами: плашки появляются по очереди с интервалом 0,3 секунды,
стрелка мягко поворачивается при появлении. Фотография неподвижна, блёстки и пульсация выключены. Это пока один пробный шаблон;
остальная недельная серия будет подготовлена после проверки.

`python make_video.py --date 2026-10-01 --slots 11:00 "13:30 или 14:00" 18:00 --poster preview.png -o preview.mp4`

Бот использует этот макет автоматически при запуске обновлённой версии. В пастельном режиме
загруженные через бота фоны пока сохраняются, но не заменяют согласованный фон с моделью.
Прежние оформления доступны через `--style lines` и `--style glass`; описание ниже относится к ним.


Иван пишет боту @Gladkieliniibot дату и время (`30.09 11:00, 13:30 или 14:00, 18:00`), бот делает ролик,
присылает превью с кнопками «Опубликовать» / «Отменить» и по кнопке копирует его в @gladkie_linii_msk.

- `make_video.py` — ролик 1080×1920, 12 с. Фон — чёткая картинка из свежего набора `assets/templates`
  (`0000-default` — запасной). Два стиля чередуются по дням: `lines` (первый вариант: линии, белые плашки)
  и `glass` (стеклянные плашки выезжают, блики, блёстки). Цвет надписей подбирается под яркость фона.
  Шрифт Prata (`fonts/`), логотип `assets/logo.png` слева внизу.
- Музыка — треки из роликов канала в `assets/music`, меняются по дате; если папка пуста, `music.py` сочиняет свою.
- Фоны: каждое воскресенье в 10:00 по Москве бот просит новые (`ask-templates.yml`). Видео (до 15 с), фото и файлы-картинки
  (в том числе HEIC с iPhone), присланные боту, сохраняются в `assets/templates/<дата воскресенья>/`; в ролики идёт самый свежий набор.
- Фраза дня: первая строка сообщения без даты идёт в ролик и в подпись.
- Надписи появляются в такт музыке (доли находятся автоматически), плашки и логотип пульсируют на доли.
- `bot.py` — GitHub Actions запускает `python bot.py --loop 1500` каждые 10 минут (бот слушает по 25 минут),
  на своём сервере — `python bot.py --loop`.

Секреты репозитория: `BOT_TOKEN`, `ADMIN_CHAT_ID`. Переменная (необязательно): `CHANNEL`.
Локально: `pip install -r requirements.txt && python make_video.py --date 2026-09-30 --slots 11:00 "13:30 или 14:00" -o test.mp4`.
